# learning-to-attribute

MAttr: attribution over a model's internal variables by learning a mask with sigmoid top-k
(node / edge / MLP-neuron / SAE-latent granularity), evaluated on the MIB circuit track,
SVA+ / arithmetic sweeps, cross-task transfer, and a handful of side substrates (ViT teaser,
tiny-LM interference weights, arithmetic formats).

## Setup

```bash
bash scripts/setup.sh   # clones deps/MIB-circuit-track (our fork, pinned), uv sync, smoke check
```

## Repo layout

| Path | Contents |
|---|---|
| `src/learning_to_attribute/` | The installed package: `trainer.learn_scores` (the algorithm), `sigmoid_topk`, `masks` (every masking ablation), `schedules`, `losses`, `evaluate`; baselines (`edge_pruning`, `grad_attribution` RelP/AttnLRP, `sigmoid_das`); model/data adapters. |
| `scripts/` | Entry points, sweeps, analysis and table generation, one subdirectory per experiment substrate (table below; see also `scripts/README.md`). |
| `plots/` | One `plot_*.py` per paper figure, shared `palette.py`; outputs are copied into `paper/figs/`. |
| `paper/` | LaTeX source; every file in `paper/tabs/` is generated by a `scripts/*/make_*_table.py`. |
| `docs/` | Write-ups of sub-investigations (edge pruning baseline, UGS baseline, cause/top-k, interference weights, arithmetic formats, Adam-vs-SGD). |
| `results/` | One directory per run, `<variant>_<optim>_lr_<lr>/<task>_<model>_<split>.pkl`. Which directory is the paper's headline is recorded in `CLAUDE.md`. |
| `deps/MIB-circuit-track/` | Clone of **our fork** `aryamanarora/MIB-circuit-track` (with the EAP-IG submodule), made by `bash scripts/setup.sh` at a pinned commit; gitignored. Its `evaluate_area_under_curve` returns 7 values, upstream's 5 breaks `eval_mib*.py`. Its TL 2.15.4 stack is the `tl2` uv dependency group (own env `.venv-tl2`), mandatory for any gemma2 cell. |

## `scripts/` subdirectories

Every group has python entry points at its top level, cluster launchers (`submit_*.sh`,
`*.sbatch`, pipeline stages) under `launch/`, and YAML configs under `configs/`. Run
everything from the repo root, e.g. `python scripts/mib/eval_mib.py ...` or
`bash scripts/sva/launch/submit_sva_sweep.sh`.

| Directory | Experiment set | Main entry points |
|---|---|---|
| `scripts/mib/` | MIB circuit track, node and edge level: MAttr runs, LR sweeps, ablations, Node/Edge Pruning and gradient baselines, gemma re-evaluation, all `paper/tabs/mib_*`, `lr_sweep`, `edge_lr_sweep`, `hparams_*`, `paired_tests`, `ladder_nestedness` tables. | `eval_mib.py`, `eval_mib_edge.py`, `eval_mib_edge_pruning.py`, `make_mib_table.py`, `make_mib_test_table.py`, `launch/mib_node.sbatch`, `launch/mib_edge.sbatch` |
| `scripts/sva/` | SVA+ and arithmetic sweeps over node, MLP-neuron and SAE substrates; optimizer / Adam-eps / cause-direction / zero-ablation / compute-matched follow-ups; fingerprint and top-neuron tables. | `eval_sva.py`, `launch/sva_sweep.sbatch`, `launch/submit_sva_sweep.sh`, `make_fingerprint_tables.py`, `analyse_cause.py` |
| `scripts/transfer/` | Cross-task transfer of llama3 attribution scores (13x13 matrix). Imports `eval_mib` from `scripts/mib/`. | `eval_transfer_mib.py`, `prep_transfer_sources.py`, `collect_transfer.py` |
| `scripts/vit/` | ViT-B/16 teaser: patch attribution, held-out faithfulness, sparsity ladder, optimizer x LR x eps grid. Deps are the `vit` uv group (conflicts with the default `lm` group), run via `UV_PROJECT_ENVIRONMENT=.venv-vit uv run --no-default-groups --group vit python ...`. | `vit_teaser_attr.py`, `vit_teaser_faith.py`, `vit_teaser_optim.py`, `launch/vit_teaser.sbatch` |
| `scripts/vw/` | Interference-weights replication on a tiny LM: data, training, scores, MAttr, pruning, transcoder features, audit; staged pipeline in `launch/vw_stage*.sh`. | `vw_train.py`, `vw_mattr.py`, `vw_prune.py`, `make_vw_tables.py`, `launch/vw.sbatch` |
| `scripts/arith_formats/` | Arithmetic-format circuits (probes, MAttr ablations, per-format tables). | `run_model.py`, `analyse.py`, `make_tables.py`, `launch/arith.sbatch` |
| `scripts/tools/` | Repo utilities. | `lock_paper.sh`, `test_attnlrp_hf.py` |
| `tests/` | Pure-torch unit tests (`uv run python -m pytest tests`). | `test_sigmoid_topk.py` |
