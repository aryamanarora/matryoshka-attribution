# learning-to-attribute

MAttr: attribution over a model's internal variables by learning a mask with sigmoid top-k
(node / edge / MLP-neuron / SAE-latent granularity), evaluated on the MIB circuit track,
SVA+ / arithmetic sweeps, CausalGym-style interchange interventions, and a handful of side
substrates (ViT teaser, toy models, tiny-LM interference weights, global-KL circuits).

## Repo layout

| Path | Contents |
|---|---|
| `src/learning_to_attribute/` | The installed package: `trainer.learn_scores` (the algorithm), `sigmoid_topk`, `masks` (every masking ablation), `schedules`, `losses`, `evaluate`; baselines (`edge_pruning`, `grad_attribution` RelP/AttnLRP, `sigmoid_das`); model/data adapters. |
| `scripts/` | Entry points, sweeps, analysis and table generation, one subdirectory per experiment substrate (table below; see also `scripts/README.md`). |
| `plots/` | One `plot_*.py` per paper figure, shared `palette.py`; outputs are copied into `paper/figs/`. |
| `paper/` | LaTeX source; every file in `paper/tabs/` is generated by a `scripts/*/make_*_table.py`. |
| `docs/` | Write-ups of sub-investigations (edge pruning baseline, global-KL circuits, cause/top-k, interference weights). |
| `results/` | One directory per run, `<variant>_<optim>_lr_<lr>/<task>_<model>_<split>.pkl`. Which directory is the paper's headline is recorded in `CLAUDE.md`. |
| `MIB-circuit-track/` | Symlink to the MIB repo clone; has its own `.venv` (TL 2.15.4), mandatory for any gemma2 cell. |

## `scripts/` subdirectories

Every group has python entry points at its top level, cluster launchers (`submit_*.sh`,
`*.sbatch`, pipeline stages) under `launch/`, and YAML configs under `configs/`. Run
everything from the repo root, e.g. `python scripts/mib/eval_mib.py ...` or
`bash scripts/sva/launch/submit_sva_sweep.sh`.

| Directory | Experiment set | Main entry points |
|---|---|---|
| `scripts/mib/` | MIB circuit track, node and edge level: MAttr runs, LR sweeps, ablations, Node/Edge Pruning and gradient baselines, gemma re-evaluation, cross-method rank comparisons, all `paper/tabs/mib_*`, `lr_sweep`, `edge_lr_sweep`, `cpr_summary` tables. `configs/` has the per-(task, model) YAMLs. | `eval_mib.py`, `eval_mib_edge.py`, `eval_mib_edge_pruning.py`, `make_mib_table.py`, `make_mib_test_table.py`, `launch/mib_node.sbatch`, `launch/mib_edge.sbatch` |
| `scripts/sva/` | SVA+ and arithmetic sweeps over node, MLP-neuron and SAE substrates; optimizer / Adam-eps / cause-direction / zero-ablation / compute-matched follow-ups; fingerprint and top-neuron tables. | `eval_sva.py`, `launch/sva_sweep.sbatch`, `launch/submit_sva_sweep.sh`, `make_fingerprint_tables.py`, `analyse_cause.py` |
| `scripts/transfer/` | Cross-task transfer of llama3 attribution scores (13x13 matrix). Imports `eval_mib` from `scripts/mib/`. | `eval_transfer_mib.py`, `prep_transfer_sources.py`, `collect_transfer.py` |
| `scripts/causalgym/` | Span-aligned interchange-intervention attribution on CausalGym, NPI and arithmetic-wild: DAS, neuron and Gemma Scope SAE variables, multitask DAS, Transluce / logit-lens feature lookups, arithmetic tables. `configs/` has the `attribute.py` YAMLs. | `attribute.py`, `attribute_multitask.py`, `attribute_sae.py`, `attribute_arith.py`, `launch/run_arith.sbatch` |
| `scripts/global_kl/` | Global circuits under a KL-to-clean objective on FineWeb-Edu. | `eval_global_kl.py`, `collect_global_kl.py`, `launch/global_kl.sbatch` |
| `scripts/toy/` | Toy linear / bilinear / quadratic / variance models and loss-AUC comparisons of MAttr against IxG / IG. (Companion `plots/toy_*.py` stay in `plots/`.) | `toy_bilinear.py`, `toy_linear_*.py`, `compare_bilinear_lossauc.py` |
| `scripts/vit/` | ViT-B/16 teaser: patch attribution, held-out faithfulness, sparsity ladder, optimizer x LR x eps grid. Runs in `.venv-vit`. | `vit_teaser_attr.py`, `vit_teaser_faith.py`, `vit_teaser_optim.py`, `launch/vit_teaser.sbatch` |
| `scripts/vw/` | Interference-weights replication on a tiny LM: data, training, scores, MAttr, pruning, transcoder features, audit; staged pipeline in `launch/vw_stage*.sh`. | `vw_train.py`, `vw_mattr.py`, `vw_prune.py`, `make_vw_tables.py`, `launch/vw.sbatch` |
| `scripts/impossibility/` | Replication of the Bilodeau et al. impossibility benchmark. | `impossibility_bench.py`, `impossibility_report.py` |
| `scripts/tools/` | Repo utilities. | `lock_paper.sh`, `monitor_jobs.sh`, `test_attnlrp_hf.py` |

## Conventions worth knowing

See `CLAUDE.md` for the load-bearing ones: the `sufficient` / `necessary` intervention
convention, which `results/` directory is the current headline, the llama3 200-example
validation cap, and the gemma2 venv rule.
